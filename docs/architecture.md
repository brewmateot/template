# Arquitectura

## Estado

Este documento es la referencia inicial de arquitectura. Complétalo cuando se definan los componentes del sistema.

## Principios

- Separar responsabilidades entre dominio, infraestructura y entrada/salida.
- Mantener dependencias explícitas y acotadas.
- Diseñar interfaces verificables mediante pruebas automatizadas.
- Preferir cambios reversibles y decisiones documentadas.
