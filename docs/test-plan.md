# Plan de pruebas

## Objetivo

Verificar que el sistema cumple sus contratos funcionales, de seguridad y operativos.

## Capas

- **Unitarias:** reglas y unidades aisladas.
- **Integración:** colaboración entre componentes y servicios.
- **End-to-end:** flujos críticos completos.
- **Seguridad:** validación de entradas, permisos y dependencias.

## Criterios de aceptación

- Todo cambio de comportamiento tiene una prueba reproducible.
- Las pruebas críticas pasan en CI.
- Los fallos intermitentes se registran y se corrigen, no se silencian.

Documenta aquí fixtures, datos sintéticos, servicios externos y diferencias entre entornos.
