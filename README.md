# Template

Punto de partida para un proyecto mantenible y verificable.

## Estructura

- `src/`: código de producción.
- `tests/`: pruebas.
- `docs/`: arquitectura, operación, plan de pruebas y ADRs.
- `.github/`: colaboración, agentes y CI.

La configuración que debe completarse en la organización (Project, ruleset de `main`, revisores y Environments) está en [docs/governance.md](docs/governance.md).

## Desarrollo local

El proyecto todavía no fija un lenguaje o framework. Documenta aquí los requisitos de instalación, el comando de desarrollo y los comandos de prueba cuando se concrete la implementación.

## Validación

Antes de enviar cambios, ejecuta las comprobaciones definidas por el stack elegido y revisa que la documentación siga siendo correcta.

## Contribución

Consulta `AGENTS.md` y las plantillas de issues y pull requests. Los cambios deben incluir pruebas cuando modifiquen comportamiento.
